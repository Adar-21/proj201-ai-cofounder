<original_problem_statement>
The user wants to build a mobile MVP called AppliFix.

**Core Problem:** People in big cities struggle to find trusted, fairly priced home repair professionals (plumbers, electricians, appliance repair).

**Target Audience:** 25–40 year old renters in Istanbul.

**MVP Goal:**
1.  **Submit Request:** Users can submit a home repair issue using a photo/video and a short text description.
2.  **AI Assistance:** The app will provide an AI-assisted category suggestion (e.g., plumbing, electrical) and a brief problem summary. A disclaimer about it being an estimate is mandatory.
3.  **Find Technicians:** Users see a ranked list of verified technicians based on ratings, distance, availability, and estimated price.
4.  **Booking & Payment:** Users can book an appointment and complete a mock escrow-style payment (no real payment integration).
5.  **Dual Roles:** The application must support two distinct roles: User and Technician, each with their own separate login and application flow.

**Tech Stack:**
-   **Frontend:** React Native (Expo)
-   **Backend:** FastAPI
-   **Database:** MongoDB
-   **AI:** A simple, lightweight LLM call for classification.

**Key Deliverables:**
-   Complete source code for both frontend and backend.
-   Instructions to run the app locally.
-   Seed data for demonstration purposes.
-   A demo script for the main user flow.
